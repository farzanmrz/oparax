# docs

- `findings.md`: discovery evidence and outreach numbers, backed by exchanges.
- `reshad.md`: Reshad's record, read separately as a family comparator.
- `people.tsv`: do-not-recontact list. People worth contacting again are recorded in `findings.md`.
- `exp1.md`, `exp2.md`, etc.: one document per experiment.

Organize experiments as **Learn → Measure → Build**. Learn states the central leap of faith and its observable hypotheses briefly. Do not require a separate Belief section or a fixed number of assumptions.

Measure defines the audience, window, evidence, decision rules, price and costs. Build specifies the offer, necessary product behavior, technical approach and what is removed. Keep facts, proposed operating choices and unresolved access dependencies distinguishable. Derive these sections in that order when requested.

Use plain language, headings and short lists, with no tables. Evidence stays in discovery records; no evidence inventory, framework worksheets, repetitive disclaimers or empty sections. Technical detail belongs where it changes what gets built or how results are interpreted.
