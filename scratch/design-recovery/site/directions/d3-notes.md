# Direction 3: monitoring desk

An original free composition informed by workflow and application layouts. This is not a React Bits Pro marketing or Application UI block. Public paid block previews provided category context; no locked source was read or copied.

## Whole-page pattern

Landing: compact central introduction above one continuous operating surface. Sources, Oparax, and X delivery have equal heading weight. The original source uses free stock shadcn Tabs. The center is a real React Bits workflow component, with match, grouping, and synthesized-story stages. Source selection changes the matched report and highlights the fact through an explicit source-URL mapping from evidence.ts (post: launch, report: mission aim, update: solar arrays). The right column is the shared authored black X DM illustration and opens the local story preview.

Feed: three-region application. A stock shadcn Sidebar provides a real publisher filter and beat context. The center shows every matching story with title and facts. The right region exposes the originals for the selected story, using stock Collapsible. The feed has search, both Direct and Clustered modes through the shared FeedHeading, working external links, and local story previews for clustered stories. It does not create topic categories or fake live state.

## Identity and content

Source Sans 3 supplies all type. Sea-glass teal, forest neutrals and silver lines in dark mode; pale mint and offwhite in light mode. Flat surfaces, small corner rounding, broad reading space. The direction-scoped variables leave production DESIGN.md and production theme files untouched. Mobile stacks the three working regions in reading order; reduced motion suppresses stage travel.

All content comes from the existing October 2024 sample stories, direct items and evidence. Original URLs and image credit are preserved. The sample never calls the live product, sends a DM, or reports a real monitoring run. Pricing and roadmap appear once, using the shared components. The source icons are the existing verified shared marks.

Skills used: frontend-design for composition and identity, official global shadcn for source reuse and primitive composition. The free proof demonstrates component discovery, local source adaptation and complete page composition. It does not establish paid block installation or Agent Kit access.
