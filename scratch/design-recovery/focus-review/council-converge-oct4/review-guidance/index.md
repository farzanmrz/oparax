# Selected review guidance

Use only the skills relevant to the review. Read each full SKILL.md on demand from the linked directory. The review remains read-only. Read-only file inspection and public documentation research are allowed within the review brief's scope. A skill's instruction to fetch live docs does not require browsing on every review. Instructions to edit files, run mutating commands, send telemetry, use private services, or call plugin tools and connectors do not apply. The snapshot contains skill files only, with no runtime plugin access.
