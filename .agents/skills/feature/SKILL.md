# Feature (Codex entry point)

The feature skill is one file shared with Claude Code (`/feature` there, `$feature` here). Read `.claude/skills/feature/SKILL.md` in this repository now, whole, and follow it exactly as written, in this session, with the owner watching. Its shell blocks are the mechanics (`git`, `gh`, `.claude/scripts/start.sh`, the fixed `.claude/scripts/review-lanes.py` runner, and the `/run-plan` launch its handoff reference names); its critique lanes decide what the detailed plan says; the owner's approval on the plain plan (step 4, or step 7 when the critique changed it materially) is what opens the issue, cuts `ft/<N>` (or `bf/<N>`), writes the plan files and launches the run. Where it names loading a skill bundle with Claude Code's `Skill` tool, the Codex equivalent is invoking that skill by its `$name` (e.g. `$vercel:nextjs`, `$supabase`, `$posthog:instrument-llm-analytics`), exactly as the canonical file's own `Skills:` line convention already documents; where it names `ListSkills`, check the name against the skills installed for Codex.

Planning happens once, for the whole product (owner, September 28); screens use the catalog and accepted-reference workflow in the canonical skill's references/design-tooling.md. The official global `$shadcn` replaces `$vercel:shadcn` for component guidance. The detailed plan is a component table plus one slice per component and a shared contracts file, in the exact formats the canonical skill's step 5 gives; the launch at the end is `/run-plan <N>`, not one `$build`.

Read the canonical skill's `references/pair-planning.md`. The default Codex host is `gpt-6-astra` for every planning phase, with Fable 5.1 (`claude-fable-5-1`) as the launched peer at high effort. Pass `--host astra --pair-model astra` and the explicit phase. The application controls the host model; do not relabel a different model. An explicit Sol request uses `gpt-6.1-sol` for routine phases only, with Astra still required for detail and substantial redesign. This is the same planning protocol used by amend; critique, QC and the run's build selection have their own shared instructions.
